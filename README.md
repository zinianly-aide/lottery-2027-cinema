# 2027 星河盛典 · Cinema 抽奖大屏

基于 **Three.js / WebGL** 的 2027 年会抽奖大屏演示项目。当前版本为 **2026-11-02 性能优化基线**，适配 Android 9 / Mali-G52 投影仪等性能受限设备。

## 功能

- 立方体粒子散射、聚合成「2027」、3D 球体及矩阵形态切换
- 星空、装饰体素云、环形光效和抽奖揭晓卡片
- 模拟 2,000 人抽奖池，工号输入及随机演示
- 重复中奖检查与中奖名单展示（**仅页面内状态**）
- WebGL 不可用时切换 Canvas 2D 兼容动画
- 投影仪模式隐藏操作面板

## 本次性能优化

| 参数 | low（Android 默认） | medium（其他设备默认） | high |
| --- | ---: | ---: | ---: |
| 主立方体实例 | 850 | 1,350 | 2,000 |
| 装饰方块实例 | 1,190 | 2,920 | 9,810 |
| 星空点数 | 650 | 1,300 | 2,800 |
| 目标帧率 | 30 FPS | 30 FPS | 60 FPS |
| 初始 DPR 上限 | 0.78 | 1.0 | 1.5 |

低画质档使用更轻量的材质，关闭部分抗锯齿，并且在帧率持续低于阈值时逐步降低渲染分辨率。这些是**代码上的优化设置**，不代表已经在所有投影仪上实测达到目标帧率。

## 本地运行

项目为静态网页，需通过 HTTP 服务访问（不要直接以 `file://` 打开模块）：

```bash
cd /path/to/lottery-cinema
python3 -m http.server 8769 --bind 0.0.0.0
```

访问 `http://localhost:8769/`，或用同一局域网内的设备访问 `http://<Mac 局域网 IP>:8769/`。

支持的地址参数：

- `/?quality=low`：适合低性能投影仪
- `/?quality=medium`：平衡画质
- `/?quality=high`：完整演示配置
- `/?quality=low&fps=1`：显示 FPS、渲染倍率和 draw calls

Three.js 使用 `https://esm.sh/three@0.170.0`，因此首次启动需要能够访问该服务。

## 重要限制

- 本仓库是**演示版**，员工姓名、部门均为模拟数据；工号为 0001–2000。
- 中奖状态仅存在浏览器内存中，刷新页面会丢失，**尚无持久化/多终端同步**。
- 没有管理员认证和权限控制，**请勿直接用于正式的公开抽奖系统**。
- 当前低画质模式只减少**视觉方块数量**，并没有减少抽奖池人数。
- 正式年会使用前，需要补充真实名单导入、中奖数据持久化、重复中奖跨端校验、权限控制和投影仪 FPS 实测。

## 结构

- `index.html` — 页面和演示控制区
- `app.js` — Three.js 主场景、动画及模拟抽奖逻辑
- `voxel.js` — 装饰体素云
- `fallback.js` — Canvas 2D 兼容显示
- `projector.css` / `cinema.css` — 投影仪和影院视觉样式
