# 2027 星河盛典 · Cinema 抽奖大屏

基于 **Three.js / WebGL** 的 2027 年会抽奖大屏演示项目。当前版本为 **2026-11-02 性能优化基线**，适配 Android 9 / Mali-G52 投影仪等性能受限设备。

## 功能

- 立方体粒子散射、聚合成「2027」、3D 球体及矩阵形态切换
- 星空、装饰体素云、环形光效和抽奖揭晓卡片
- 模拟 2,000 人抽奖池，工号输入及随机演示
- 重复中奖检查与中奖名单展示（**仅页面内状态**）
- WebGL 不可用时切换 Canvas 2D 兼容动画
- 投影仪模式隐藏操作面板

## 本次性能优化

| 参数 | low（Android 默认） | medium（其他设备默认） | high |
| --- | ---: | ---: | ---: |
| 主立方体实例 | 850 | 1,350 | 2,000 |
| 装饰方块实例 | 1,190 | 2,920 | 9,810 |
| 星空点数 | 650 | 1,300 | 2,800 |
| 目标帧率 | 30 FPS | 30 FPS | 60 FPS |
| 初始 DPR 上限 | 0.78 | 1.0 | 1.5 |

低画质档使用更轻量的材质，关闭部分抗锯齿，并且在帧率持续低于阈值时逐步降低渲染分辨率。这些是**代码上的优化设置**，不代表已经在所有投影仪上实测达到目标帧率。

## 本地运行

项目为静态网页，需通过 HTTP 服务访问（不要直接以 `file://` 打开模块）：

```bash
cd /path/to/lottery-cinema
python3 -m http.server 8769 --bind 0.0.0.0
```

访问 `http://localhost:8769/`，或用同一局域网内的设备访问 `http://<Mac 局域网 IP>:8769/`。

支持的地址参数：

- `/?quality=low`：适合低性能投影仪
- `/?quality=medium`：平衡画质
- `/?quality=high`：完整演示配置
- `/?quality=low&fps=1`：显示 FPS、渲染倍率和 draw calls

Three.js 使用 `https://esm.sh/three@0.170.0`，因此首次启动需要能够访问该服务。

## 重要限制

- 本仓库是**演示版**，员工姓名、部门均为模拟数据；工号为 0001–2000。
- 中奖状态仅存在浏览器内存中，刷新页面会丢失，**尚无持久化/多终端同步**。
- 没有管理员认证和权限控制，**请勿直接用于正式的公开抽奖系统**。
- 当前低画质模式只减少**视觉方块数量**，并没有减少抽奖池人数。
- 正式年会使用前，需要补充真实名单导入、中奖数据持久化、重复中奖跨端校验、权限控制和投影仪 FPS 实测。

## 结构

- `index.html` — 页面和演示控制区
- `app.js` — Three.js 主场景、动画及模拟抽奖逻辑
- `voxel.js` — 装饰体素云
- `fallback.js` — Canvas 2D 兼容显示
- `projector.css` / `cinema.css` — 投影仪和影院视觉样式


## Cinema V3 · 动画调速与粒子特效

页面右上角（Android 投影仪为右下角）点击 **「动画控制」**，可以使用：

- 调速滑条：**0.25×–3.00×**，快速按钮 **0.5×、1×、1.5×、2×**。
- **暂停 / 继续**：停止/恢复粒子形变、星云旋转和镜头运动。帧率目标不随倍速改变，避免因加速导致过度渲染。
- **配色**：银河蓝 → 霓虹紫 → 鎏金色，可循环切换主粒子与装饰粒子色彩。
- **粒子绽放**：触发可复用的径向星光爆发和金色/霓虹冲击波；中奖时自动触发鎏金爆发。
- **光效强度**：0–1.7 倍，可降低亮度以改善投影对比度。

本次引入轻量的 **双层银河光点、发光圆形粒子精灵、流星拖尾、可重复使用的粒子爆发缓冲区和环形冲击波**，按 low/medium/high 档位动态控制粒子数。特效增加少量 draw calls，避免大规模透明后处理。

倍速通过**统一虚拟动画时钟**控制场景运动及 2027 形态切换，避免加速时增加 draw calls；中奖卡片展示时间仍按现实时间计算，以保证现场易读性。无法使用 WebGL 时，2D fallback 也支持调速与基础特效。

## Cinema V4：3 秒倒计时 + 六位工号翻牌揭晓

这一版增加了与 3D 粒子背景解耦的 HTML/CSS 记分牌组件；在低画质投影仪上播放翻牌时，会暂停被遮住的 WebGL 场景绘制，以避免不必要的 GPU 开销。

- 工号统一显示为 **6 位**。当前 2,000 人演示池为 `000001`–`002000`；仍可输入较短的数字，系统会自动补齐前导零。
- 前三位固定显示，后三位起初显示 `? ? ?`；**倒计时结束后，按百位→十位→个位逐张翻牌**。
- 中奖名单在开始播放前已由队列确定。翻牌只是展示动画，**不会在过程中重新随机抽人**。
- 完整揭晓姓名、部门和模拟头像文字后，加入页面中奖墙；实际头像文件尚未导入。
- 在控制台选择奖别和节奏：**普通**（3 秒倒计时，三张牌每张 0.5 秒）、**大奖**（3 秒倒计时，慢翻每张 0.72 秒）、**快速**（1 秒倒计时，每张 0.26 秒）。
- 连续抽同一个奖别时，可选择让后续单人揭晓自动使用快速模式；演示按钮支持 **5 位同屏同步翻牌**。
- 本页内防重复：中奖过或排队中的工号不能再次进入队列；点击重置会取消未完成的定时器。注意**刷新页面会丢失全部名单状态**。

操作：打开 [GitHub Pages Demo](https://zinianly-aide.github.io/lottery-2027-cinema/?v=cinema4)，在电脑上的「现场控制台」选择奖项、模式，输入工号如 `000123` 并点击「翻牌揭晓」。若使用 Android 投影仪，控制台默认隐藏，应通过有操作面板的电脑浏览器演示；当前静态 Demo **没有跨设备同步**，不能直接用电脑控制另一个设备的页面。

第三方开发者可在浏览器控制台调用：

```js
window.cinemaLottery.enqueue('000123', {prize:'一等奖', mode:'grand'});
window.cinemaLottery.enqueue([123,456,789,1001,2000], {prize:'二等奖',mode:'normal'});
```
